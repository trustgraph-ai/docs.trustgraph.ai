# Context Graph viewer

You've seen the knowledge graph through the Graph Explorer and queried
it with SPARQL. The Context Graph viewer gives you another perspective
— an interactive visualisation of how knowledge, context, and
provenance connect.

## Open the Context Graph

From the Workflows page, select **Context Graph**.

This view shows the full context structure: how documents were
processed, how knowledge was extracted, and how entities and
relationships connect. It's a higher-level view than the Graph
Explorer — less about individual nodes and more about the overall
knowledge architecture.

## What to look for

- **Document provenance** — trace from extracted knowledge back to
  the source documents and specific text chunks
- **Collection structure** — see how different documents and
  extractions are organised within collections
- **Relationship density** — identify which entities are highly
  connected and which are isolated

This is particularly useful when you're working with multiple
documents and ontologies — the Context Graph shows how everything
fits together.
