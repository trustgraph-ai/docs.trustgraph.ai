# Help and Resources

Where to get help and find useful resources for contributing to TrustGraph.

## Community

- **[Discord](https://discord.gg/sQMwkRz5GX)** — Main community hub
  - `#contributing` — Design guidance and contribution support
  - `#general` — General discussion
  - `#help` — Technical help and troubleshooting

## GitHub

- **[trustgraph](https://github.com/trustgraph-ai/trustgraph)** — Core repository
- **[Issues](https://github.com/trustgraph-ai/trustgraph/issues)** — Bug reports and feature requests
- **[Discussions](https://github.com/trustgraph-ai/trustgraph/discussions)** — Questions and ideas
- **[Pull Requests](https://github.com/trustgraph-ai/trustgraph/pulls)** — Contribute code

## Documentation

- **[How-to Guides](../guides/)** — Task-focused guides
- **[Reference](../reference/)** — CLI, APIs, configuration
- **[Deployment](../deployment/)** — Installation and cloud deployment

- `TEST_STRATEGY.md` — Testing approach and conventions
- `docs/tech-specs/` — Technical specifications for features
- `CHANGELOG.md` — Release history

## Related Repositories

- **[trustgraph-templates](https://github.com/trustgraph-ai/trustgraph-templates)** — Deployment configuration templates
- **[workbench-ui](https://github.com/trustgraph-ai/workbench-ui)** — Workbench UI application
