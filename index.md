# Get Started

Choose the path that fits where you are.

**[Learn about TrustGraph](learn/)** — what it is, how it works,
and whether it's right for you. Start here if you're evaluating
TrustGraph or want to understand the concepts before diving in.

**[Quickstart](quickstart/)** — get TrustGraph running, load data,
and query a knowledge graph in under 30 minutes. Start here if
you want to see it work with your own eyes.

**[Build an App](build-an-app/)** — build a TrustGraph UI plugin
from scratch, from ontology design through to production
deployment. Start here if you're ready to build something real.
